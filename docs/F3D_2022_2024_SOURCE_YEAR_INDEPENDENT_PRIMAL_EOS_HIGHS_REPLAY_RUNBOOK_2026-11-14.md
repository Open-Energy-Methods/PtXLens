**Status 2026-11-14:** ready and regression-tested, but **not yet executed on real 2022/2024 ERA5 pairs**. No 2022/24 combined-year operational savings or v1.0 claims are yet admitted.

## Distinct levels of scientific evidence

1. **Authentic original provider source:** PtXFlex acquires 14 original monthly ENTSO-E A44 NL XML documents per source year (including bracketing months), and 12 original ERA5 NetCDF monthly files of four 10/100m wind components. Each year must be complete in UTC (2022: 8760, 2024: 8784). Reconstructed **2023 price and wind** must separately match the frozen original PyNEXUS full-year float64 SHA vectors before any 2022/24 alternative-year pair is used. Licences and permanent independent source storage are separate checks.
2. **PtXFlex operational optimization:** original E(20t) and E+S(40t) model, 50t/day flat source demand, price-independent maximum feasible constant E delivery fraction *within each historical source year and each capacity semantics*, then E and E+S HiGHS MILPs constrained to the exact same hourly H2 target with 200bar Type I screen, fixed compressor power and source-year NL wholesale prices. Both must reach certified relative MILP gaps ≤1e-6 with independently audited primal mass/energy balances and finite dual objective bounds.
3. **PtXLens metadata/finance cross-check:** `src/ptxlens/f3d_external_year_independent_review.py` independently checks both years × two modes, year length, E/ES target SHA equality, native IEEE-754 target hash, alpha annual H2 arithmetic, E-ES signed objective savings and interval from both dual bounds, pressure-screen and explicit industrial/LCA/DCF non-release flags. Hermetic unit tests in `tests/test_f3d_external_year_independent_review.py`. **This is not a second MILP solve.**
4. **PtXLens independent FULL-hour source physical replay:** `src/ptxlens/f3d_external_year_private_witness_replay.py` accepts separate original-year private source normalized price/wind files, a corresponding PRIVATE PtXFlex full 8-state×year E-selector and E/ES dispatch witness, and the aggregate solver report. It independently checks every hour's UTC alignment, source SHA, H2 delivery, original source PEM production and ramp/commitment, signed electric grid exchange and wind curtailment, 20t/40t Type I bank charging/discharging, cyclic inventory losses and 20/200bar absolute pressure using independent CoolProp hydrogen EOS, independent annual signed-grid price costs and source compressor charge energy. **No PtXFlex physics/solver modules are imported.** Tested on hermetic algebraic fixtures, not yet on authentic full-year provider data. The module does not independently derive HiGHS global dual certificates or confer vendor compressor/manufacturing validation.

## Execution after provider-sourced 2023 calibration passes

Source acquisition run: [PtXFlex primary provider workflow](https://github.com/Open-Energy-Methods/PtXFlex/actions/runs/43617006319). Current original target run ID is `43617006319`.

The four source-year/mode cases are generated by `PtXFlex/.github/workflows/f3d-matched-year-service-from-private-source.yml`. Its `workflow_dispatch` will work once the workflow is on GitHub's default branch. On the current draft research branch it can alternatively be launched by **committing** the prearranged source-ready marker `research/F3_D_SOURCE_PAIR_READY_TRIGGER.json` only after all six provider jobs and the three source-pair gates pass; do not create that marker prematurely. This prevents costly/error-prone runs on unverified weather or missing archives. The workflow creates:

- Four **aggregate-only** output artifacts named `F3D-{year}-{mode}-strict-same-hour-H2-HiGHS-LCA-NOT-PASSED` (no hourly original source prices, winds or dispatch arrays; 30-day retention).
- Four **PRIVATE full-hour primal witness** artifacts named `PRIVATE-F3D-{year}-{mode}-primal-witness-NOT-public` (7-day retention). These contain 8-state E selection and E/ES hourly model dispatch but not duplicated original provider arrays. Original provider archives are in their own short-lived private source artifact family. Preserve them in lawful independent private storage before expiry.

### Independent metadata review

Obtain the four aggregate-only JSON reports, keep each year/mode distinct, then run:

```bash
python -m ptxlens.f3d_external_year_independent_review \
  --files PRIVATE/F3D_2022_max_inventory.json PRIVATE/F3D_2022_usable_service.json \
          PRIVATE/F3D_2024_max_inventory.json PRIVATE/F3D_2024_usable_service.json \
  --output PRIVATE/F3D_2022_2024_PtXLens_four_case_metadata_review.json
```

This must fail if 2024 is truncated, 2023 source anchor flags are absent, target hourly SHA differs across E/ES, the two original physical mode interpretations are mixed, the E-selector is not price-independent and integer-bound certified, or source case cost differences do not close against both HiGHS objective lower bounds.

### Independent full-hour primal and independent hydrogen EOS review

Install `CoolProp==8.0.0` for the original Type-I source hydrogen EOS. **Execute privately**, with no raw/provider data copied into either repository:

```bash
python -m ptxlens.f3d_external_year_private_witness_replay \
  --witness PRIVATE/PRIVATE_F3D_2024_usable_service_FULL_PRIMAL_WITNESS.json \
  --aggregate-report PRIVATE/F3D_2024_usable_service.json \
  --private-price PRIVATE/entsoe-2024/normalized_UTC_price.csv \
  --private-wind PRIVATE/era5-2024/normalized_UTC_wind.csv \
  --output PRIVATE/PtXLens_2024_usable_service_independent_hourly_EOS_and_wholesale_replay.json
```

Repeat for each of the four cases and register the independent verifier's code revision, original provider/solver witness SHA256s, pass/fail status and data custody. The resulting reviewer JSON contains only aggregate residuals, EOS min/max, modelled nominal-year cost checks and SHA fingerprints; original private hourly source values and case dispatch arrays are never emitted.

Cross-year 2022/24 nominal EUR differences are not comparable as discounted investment cash flows without explicit year-price normalization, site tariffs and relevant future uncertainty.
